# Turbo C++ Program Collection

A curated collection of 222 C++ source files gathered from the `BIN` folder of a Turbo C++ installation. Programs are grouped by their apparent subject to make the collection easier to browse. Original source filenames and contents are preserved.

## Topics

| Folder | Focus | Programs |
| --- | --- | ---: |
| `01-fundamentals-and-operators` | Expressions, data types, operators, and conversions | 26 |
| `02-conditionals-and-loops` | Decisions, branches, and loop exercises | 49 |
| `03-arrays` | One-dimensional and multidimensional arrays | 20 |
| `04-strings` | C-style strings and string operations | 10 |
| `05-functions` | Function calls, arguments, and reusable routines | 10 |
| `06-pointers-and-memory` | Pointers, pointer arrays, and dynamic memory | 14 |
| `07-classes-and-oop` | Classes, constructors, inheritance, and polymorphism | 35 |
| `08-file-handling` | File input and output exercises | 9 |
| `09-data-structures-and-algorithms` | Stacks, sorting, searching, and related exercises | 7 |
| `10-input-output-and-formatting` | Console input/output and formatting manipulators | 15 |
| `11-math-and-number-exercises` | Arithmetic, number properties, and series | 11 |
| `12-miscellaneous` | Exercises that do not fit the topics above | 16 |

## Compatibility

These programs were written for the legacy Turbo C++ environment. Some may use compiler-specific headers or features, such as `conio.h`, and may need changes before they compile with a modern C++ compiler. This repository preserves the original examples; it does not claim that every program builds on current toolchains.

## Repository contents

Only `.CPP` source files and this README are included. Turbo C++ executables, object files, backup files, compiler libraries, and other installation files are excluded.
